# 0.5.0.dev9 缓存中断与安装入口回归

持续测试复现五项问题，均已补充先失败后通过的回归。资料写入中断会留下空记录，同版本并发添加
会读取未完成 JSON，并发撤回会覆盖首个原因，空撤回记录会被当作未撤回，安装 launcher 可能加载
当前目录或 PYTHONPATH 中的同名模块。

资料和撤回记录复用同目录临时文件、flush/fsync 和操作系统锁，在锁内检查目标并原子发布。
目标锁沿用同一跨进程实现，正常写入仍使用原子替换。撤回记录读取时校验必需字段。
安装器生成的 POSIX/Windows launcher 使用 Python 隔离模式，专用环境承担模块解析。

新增六项回归，覆盖编码及锁内发布前进程退出、并发添加／撤回、损坏撤回、无硬链接能力与安装入口模块解析。

## 已发现的兼容问题

1. main 文档有 `sch compose schema`，Release v1.16.0 没有。必须探测实际 help。
2. Release 源码只接受十类 pagePrimitives，本次现场返回十一类（含 pins）。
   用十一类合成快照对同一发布 CLI 的离线 compose 可复现 `incomplete class inventory`；
   十类合成快照编译/dry-run通过。版本号一致不能证明结构兼容。
3. `layout-lint` 是 bare JSON，以 `ok` 判定；DRC/check/bridge 是 result envelope，以 `passed` 判定。
4. DRC 可能没有完整计数或 UI 明细；缺失必须原样说明。
