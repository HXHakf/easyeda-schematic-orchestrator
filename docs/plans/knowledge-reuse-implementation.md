# 知识库复用与组合实现计划

依据：本次会话用户明确批准的《知识库优化修订计划》。保持嘉立创核心、原厂参数依据、私有资料隔离和精确设计确认。

1. 真实资料可行性：MMBT3904LT1G、AO3400A、电阻；记录证据及无法保证的条件，不为现场通过编造参数。
2. v2 输入/功能：最小最大供电、导通电流需求、关闭电流、温度范围、结构化事实与条件化推导。
3. 私有不可变资料缓存：导入、增加、列表、撤回；文档定位外置、内容哈希和精确身份；工程计算不缓存。
4. v2 依赖证据：限定当前依赖；完整契约确认不放宽；旧格式保持原校验；迁移不继承确认。
5. doctor 与安装：只读本地/现场诊断，打包现有渲染器、macOS 浏览器发现。
6. 有限 MCU 组合：显式 GPIO/供电/地绑定、预算与高阻依据、位号和网络隔离、全计划重验。
7. 指标/文档/发布检查：记录阻断任务及耗时分类；完整单测、离线演示、独立安装、独立审查。
8. 现场：仅在真实参数、完整设计确认和工具条件满足后执行两类及组合样例，保存重开回读。否则保留开发版与阻断证据。
