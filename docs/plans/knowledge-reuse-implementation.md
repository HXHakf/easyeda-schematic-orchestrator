# 通用工作流发布与项目应用范围

依据用户最新修订，当前交付为通用原理图绘制工作流，常用知识库以嘉立创资料为核心，原厂资料补充原理与计算方法。

## 当前发布验收

- 六个唯一主题具有用途、适用条件、通用连接、参数或计算方法、错误反例与来源定位。
- 原理图设计规范、输入与确认接口、计划和绑定、布局测量、执行、回读、恢复及证据索引可用。
- 完整单元测试、离线演示、独立安装和跨平台回归通过，代表性样例完成 EDA 流程验收。
- 知识与来源按稳定 ID 去重，具体器件资料保存为项目记录或私有缓存。

## 项目开始后确定

应用场景、具体模块与器件、完整型号、封装、数据手册、工作电压、电流、温度、接口条件和散热依据由具体项目确定。
宿主据此选择通用知识卡、审阅手册、核验真实物理脚、计算参数并生成设计契约。
项目资料不完整时，使用现有缺项提示与确认检查处理该项目。

效率指标在具体项目中持续采集，按实际任务范围比较。测试型号的手册摘录和电气验证保留各自的项目结论。

## 历史分阶段开发计划

以下保留当时的实施顺序，版本发布范围采用上文的最新用户修订。

# 知识库复用与组合实现计划

依据：本次会话用户明确批准的《知识库优化修订计划》。保持嘉立创核心、原厂参数依据、私有资料隔离和精确设计确认。

1. 真实资料可行性：MMBT3904LT1G、AO3400A、电阻；记录证据及无法保证的条件，不为现场通过编造参数。
2. v2 输入/功能：最小最大供电、导通电流需求、关闭电流、温度范围、结构化事实与条件化推导。
3. 私有不可变资料缓存：导入、增加、列表、撤回；文档定位外置、内容哈希和精确身份；工程计算不缓存。
4. v2 依赖证据：限定当前依赖；完整契约确认不放宽；旧格式保持原校验；迁移不继承确认。
5. doctor 与安装：只读本地/现场诊断，打包现有渲染器、macOS 浏览器发现。
6. 有限 MCU 组合：显式 GPIO/供电/地绑定、预算与高阻依据、位号和网络隔离、全计划重验。
7. 指标/文档/发布检查：记录阻断任务及耗时分类；完整单测、离线演示、独立安装、独立审查。
8. 现场：仅在真实参数、完整设计确认和工具条件满足后执行两类及组合样例，保存重开回读。否则保留开发版与阻断证据。

版本：0.4/0.5 的软件能力可先交付开发版；未完成现场闭环不得宣称该里程碑完成。
