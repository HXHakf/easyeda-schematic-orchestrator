# 常用电路知识库实施记录

当前范围采用用户最新修订，先交付通用知识卡和绘图流程，项目应用时再确定器件与模块资料。
六个主题均已具备嘉立创主来源，最新发布标准见[范围记录](knowledge-reuse-implementation.md)。
以下保留首阶段实施记录。

目标是将已选器件及数据手册映射到嘉立创为核心的唯一电路主题，在设计确认前核验条件，再复用现有 ESO 生成、测量与回读流程。

## 已实现的开发阶段

1. 资料清单和本地文件证据。宿主录入手册摘录、版本、物理引脚与真实库身份，程序集中报告缺项和矛盾。
2. 唯一来源/规则/资产/主题索引。NPN、NMOS 两张卡具有可执行静态电阻负载变体，其余四个主题保留知识卡或待补主来源候选。
3. 检索、参数检查、contract 证据、plan/bindings 生成。证据变化使旧确认和交付资格失效。
4. 离线模拟全链路测试，包含保存重开回读及失败后撤销旧成功状态。真实 EDA 测试仍需获准空白测试工程与具体器件选型。
5. 可运行示例、用户指南、安装包数据、同任务同范围的指标比较接口。

## 实施边界

- 首版可执行变体为静态电阻负载、共地、默认关闭。PWM、感性/容性负载、共享上拉、跨电源域、原生 CBB 导入尚未支持。
- 嘉立创主导主题及资产组织，原厂手册核验具体器件参数。并不因为资料来自主来源就跳过参数冲突审查。
- Python 核验结构、哈希、摘录一致性及已编码规则。手册语义、参数温度适用性和工作限值由宿主审阅。
- 不增加模型服务、向量库、绘图引擎或自动选型 API。未使用知识库的既有流程兼容。
- 所有演示使用显著标注的虚构数据，无真实选型或现场通过声明。

## 验收

相关单元测试、完整旧测试集、旧离线演示、新知识库演示与构建后安装检查分别运行。真实现场、仿真、PCB、硬件验证保持未完成。流程耗时可以自动记录，人工补参和实际连接错误在未测时保持 null，比较需要相同案例与验证范围的实测数据。
