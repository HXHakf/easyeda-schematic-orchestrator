# 0.2 独立触发行为评估

2026-11-02，独立模型只读已安装 Skill 元数据/正文，对15条互相独立的用户表达判断技能选择、
第一步与是否可以写入。没有向评估者提供预期答案，没有调用 EDA、网络或工程写入。

| 表达 | 实际选择/行为 |
|---|---|
| 我要画原理图 | 主控 Skill，先明确功能与约束 |
| 帮我设计一个STM32最小系统 | 主控 Skill，补型号/供电 |
| 画5V转3.3V的LDO | 主控 Skill，问负载及选型条件 |
| 补齐复位与去耦 | 主控 Skill，先核实原图与器件 |
| 修改SDA接错的线 | 主控 Skill，先回读核实端点，不能直接编辑 |
| 先给温湿度方案，不要画图 | 仅主控规划，不进入绘图执行 |
| I2C是什么 | 原理解释，不触发绘图流程 |
| 解释这张原理图 | 解释，不触发绘图流程 |
| 写STM32的I2C驱动 | 嵌入式/代码开发，不触发原理图流程 |
| 给PCB布线 | 上游PCB能力，不触发原理图主控 |
| 设计审批工作流 | 普通流程设计，不触发EDA |
| 用KiCad画原理图 | 遵从KiCad选择，仅需求/方案；不调用嘉立创执行器 |
| 计算电源纹波 | 工程计算，不触发绘图流程 |
| 不画图，只解释上拉 | 原理解释，遵守否定意图 |
| STM32加传感器小板，先设计电路 | 主控 Skill，先整理电路需求 |

15项评估都没有把未知型号、连接、确认或测试工程当作事实，也没有直接写入。
原理图正例可在后续需要时使用上游 easyeda-agent；只规划的请求不会因此调用绘图。

覆盖限制：这是独立模型对技能选择的语义判断，不是 Codex 桌面每轮隐式选择的统计成功率。
自动发现/启用由 Codex skills/list 另行核验；真实工程操作仍需独立端到端验收。

同轮独立代码反例发现并修复：GPIO编号前缀混淆、全页观测缺测、测量来源哈希未带入编译、
电路类型切换遗留I2C字段、验收未通过仍返回0。每项已加入对应回归测试。
